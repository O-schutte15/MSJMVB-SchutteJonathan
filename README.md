# Mount St. Joseph Men's Volleyball Website

This project originally started as the final project for my Web Development class and grew into a more complete version of the Mount St. Joseph University Men's Volleyball website.

The original version was developed from February 2026 through May 2026 and was based on the 2025–2026 season, my sophomore season. After completing the class project, I decided on improving the website over the summer by updating the design, layout, navigation, content, and overall user experience.

One of the most enjoyable parts of this project was being able to continue learning outside of the classroom. After the class ended, I was able to experiment with different ideas, research ways to improve the website, and teach myself new techniques without having an assignment or specific requirements to follow. It gave me the opportunity to learn through trial and error and figure out how to solve problems on my own.

The final version includes information about the team, schedule, game-day experience, and other features designed to give fans a better way to follow Mount St. Joseph Men's Volleyball. I also added JavaScript functionality and continued refining the site's styling to create a more polished and complete website.

This project allowed me to combine my interests in **computer science, web development, and Mount St. Joseph Men's Volleyball** into one project. What started as a class assignment became a great opportunity to challenge myself, learn independently, and build something that I could be proud of.
